# 📝 To-Do App Pro

A modern task management web application built with vanilla JavaScript.
This app allows users to create, edit, complete, and delete tasks with local data persistence and a clean user experience.

---

## 🚀 Live Demo

👉 https://danielalt17.github.io/To-Do-APP/

---

## ✨ Features

* ✅ Add new tasks
* ✏️ Edit tasks in real time
* ✔️ Mark tasks as completed
* 🗑️ Delete tasks with confirmation
* 🔎 Filter tasks (All / Pending / Completed)
* 💾 Data persistence using LocalStorage
* 🔢 Dynamic task counter
* 📭 Empty state handling
* 🎬 Smooth animations (add/remove)
* 🧠 Saves last selected filter

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage API
